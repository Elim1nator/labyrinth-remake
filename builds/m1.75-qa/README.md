# Kersplat Labyrinth: The Descent — M1.75

QA build (debug hook on). Release build in `../m1.75/`.

## What changed since M1.74.1

- **The Clockwork Mourner** (Rust Works floors only): a ticking wind-up figure in a rusted mask with 7 HP. It is the common monster there (at least 3 per floor). Every bite Rusts you for 8 s (slower, shorter throws). It walks on three frames, ticks as it walks, and shatters into gears when it dies.
- **The Tin Heart** (Rust Works only, sometimes dropped by a Mourner): a run item that makes you immune to Rust and makes your throws 15% faster.

Frozen build; sha256 in `../SHA256SUMS`.
