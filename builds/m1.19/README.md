# Kersplat Labyrinth: The Descent — M1.19

Release build (no debug hook unless `?debug`); QA build in `../m1.19-qa/`.

## What changed since M1.18

- **Title theme.** An original, hand-written 8-bit tune for the menus (title, high scores, name entry).
  - 16 bars in A minor with harmonic-minor turns, at 108 BPM.
  - A pulse-wave lead with a little vibrato, a bouncing octave bass, a 16th-note arpeggio, and kick, snare and hats.
  - Busier and a bit louder than the floor songs (about −36 dB average against −39 in game).
  - It hands over to the floor's own song when you start.
  - Browsers only allow sound after your first key press, click or tap, so it starts then.

Frozen build; sha256 in `../SHA256SUMS`.
