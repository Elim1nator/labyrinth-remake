# Kersplat Labyrinth: The Descent — M1.15

Release build (no debug hook unless `?debug`); QA build in `../m1.15-qa/`.

## What changed since M1.14.2

- **New name:** the game is now **Kersplat Labyrinth: The Descent**. The title screen, page title and home-screen name are updated, and the "prototype / placeholder title" text is gone; the version shows small in the corner.
- **No pit-spider farming:** spiders that climb out of pits (and their splitter copies) drop no coins, loot or power-ups. Spiders from the Broodmother and her egg sacs still drop as before.

Frozen build; sha256 in `../SHA256SUMS`.
