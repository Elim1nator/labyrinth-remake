# Kersplat Labyrinth: The Descent — M1.56

Release build (no debug hook unless `?debug`); QA build in `../m1.56-qa/`.

## What changed since M1.55

- New use-item, the Plunger: drop to the next floor once through a black hole, then it is used up (blocked on a sealed boss floor or the last floor).
- New monster, the Bather (4 HP): a slow hunched chase on Tiled Baths floors that leaves slick, damaging puddles.

Frozen build; sha256 in `../SHA256SUMS`.
