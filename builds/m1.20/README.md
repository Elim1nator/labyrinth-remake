# Kersplat Labyrinth: The Descent — M1.20

Release build (no debug hook unless `?debug`); QA build in `../m1.20-qa/`.

## What changed since M1.19.2

- Realistic stone walls: crystal (L17) and void runes (L25) are replaced by blue slate and ember rock.
- 7 new wall styles, one every 4 floors from L29: sandstone, granite, cobblestone, limestone, dripstone, chasm shale, ironbound stone.
- Every wall style has damaged, structural (pillared bay) and decorative (torch or glowing sigil) variations, mixed into each floor.

Frozen build; sha256 in `../SHA256SUMS`.
